
# FitLog

FitLog is a modern and responsive workout library application built with Next.js 15. It allows users to explore workouts, view exercise details, create a personal workout plan, and save favorite workouts for later.

## 🛠️ Technologies

- Next.js 15
- TypeScript
- Tailwind CSS
- React Context API
- react-hot-toast

## ✨ Key Features

1. **Workout Library** — Browse and explore a collection of workouts.
2. **Workout Details** — View exercise instructions, difficulty levels, duration, sets, and reps.
3. **My Workout Plan** — Add workouts to a personal plan and track completed exercises.
4. **Save for Later** — Save favorite workouts for quick access.
5. **Local Storage** — Keep your workout plan and saved workouts after refreshing the page.
